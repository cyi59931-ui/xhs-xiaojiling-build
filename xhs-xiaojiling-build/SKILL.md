## 二、账号定位（Building Block 1：选什么赛道、立什么人设）

### 2.1 赛道逻辑：为什么选血型×星座体质
- **高共鸣**：血型/星座自带"说的就是我"的对号入座情绪，评论区天然有话说（扣1扣2/打分/站队）。
- **低门槛 + 高辨识**：比纯星座多一层"血型体质"科学底色，让内容"像科普不像玄学"，更可信也更独特。
- **矩阵无限可扩张**：4 血型 × 12 星座 × 体质/职场/关系/影视/心理自测 → 选题排列组合极多，不易同质化、可持续更新。
- **高收藏/转发**：冷知识"原来如此"给收藏动力；身份认同给转发动力。

### 2.2 定位框架（可套用）
```
【一句话定位】专注【血型×星座体质性格】解构的【玄理科普】账号，帮【人群】完成【更懂自己 / 破偏见】。
【人群】血型星座玄学爱好者；为"为什么我这么累 / 矛盾 / 爱逃避 / 不被理解"所困、想借科学安心认识自己的年轻人。
【核心痛点】体质焦虑、性格自我怀疑、被贴标签、不知道该不该慌、觉得没人懂自己。
【差异化立场】科学包装玄学：不做恐惧式运势预测，用认知心理 / 基因概率 / 行为机制把玄学讲得可信又有温度。
【一句话简介模板】▫️专注【血型拆解】▫️解锁【体质】▫️爱上【最新版本的自己】。
```

### 2.3 人设三件套（立信任的关键）
1. **科学背书词**：认知心理学里叫"即时满足偏好" / 从血型心理学来看 / 基因概率 / 皮质醇（压力激素）——让玄学读起来像科普，读者觉得"有理有据"。
2. **咨询/研究画面**："我帮一位射手座客户画了张能量图"（#21）、"讲个真实的咨询案例（已匿名）"（#30）、"我研究了很久，发现真正的差距不在腿，而在血型"（#05）——像有手艺的命理/心理咨询师。
3. **破偏见口吻**："别急着说射手座就是作"（#24）、"不是你矫情，是体质使然"（#01）、"说真的，这不是针对你"（#13）——永远站在读者这边、替读者拆误解。

## 三、账号分析（Building Block 2：内容矩阵 & 写作引擎）

### 3.1 内容矩阵（6 类，支撑"高共鸣 + 高收藏"）
> 每类的"单篇怎么写"详见 `xhs-tianshengxiaojiling` skill 的模板 A-F，此处是战略排布。

| 类型 | 作用 | 占比建议 |
|---|---|---|
| A 血型冷知识/科普型 | 主打干货、最易收藏（置顶范例） | 每周 1-2 篇 |
| C 血型+星座组合分析型 | 对号入座、最吃矩阵（×12星座） | 每周 1-2 篇 |
| E 影视剧角色解构型 | 蹭热剧 IP、高收藏高共鸣 | 每周 1 篇 |

| F 血型对比/体质对照型 | 站队互动、轻松有梗 | 每 1-2 周 1 篇 |

### 3.2 写作引擎（每篇都带，且贯穿全号的"DNA"）
- **对号入座开口**："你身边有没有… / 你是不是… / 你有没有发现…"。
- **科学包装**：认知偏差 / 即时满足偏好 / 基因概率 / 皮质醇 / 代谢快慢 / 行为机制 / 能量模型。
- **反转破偏见**："你根本不是慢" / "别急着说【标签】" / "不是你矫情，是体质使然"。
- **❌误区 ✅真相 对仗**；**1️⃣2️⃣3️⃣ / 🅰️🅱️🅾️🆎 / ♉♌♐** 符号化排版。
- **金句收尾**："复杂，才是你最真实的样子" / "外表随和，内有城池"。
- **互动钩子**："知道的扣1，今天才知道的扣2" / "你打几分？聊聊！" / "评论区站队"。

### 3.3 价值内核（护城河，务必贯穿）
- **破偏见、反贴标签**：收尾永远给"不被定义"的出口，立场与"一个血型一个标签"的刻板账号相反 → 显真诚、像"自己人"。
- **科学底色可查**：输血/基因概率/激素等用主流口径，让玄学"可信"。
- **给可落地的建议**：不止情绪共鸣，落到"10-10-10 法则 / 长期清单 / 设底线 / 停顿三秒"等执行项 → 高价值感。

## 四、增长设计（Building Block 3：怎么从0到获赞）

1. **收藏导向**：内容给"可带走的干货"（冷知识/清单/模型/对比），结尾引导收藏。
2. **对号入座拉评论**：每个主题都让读者"认领自己是哪种"，评论区天然刷屏。
3. **互动扣数/打分**："扣1扣2"、"你打几分"、"评论区站队"→ 拉评论、养账号权重。
4. **影视 IP 借势**：知否/甄嬛传/如懿传角色×血型星座解构，蹭热剧搜索与共鸣。
5. **系列化追更钩子**："其实还有一套更高级的法则，下次拆给你看"→ 制造连续剧感、沉淀粉丝。
6. **批量铺量冷启动**：起步期一次铺满 6 类矩阵（本号 30 篇同日发布），快速立"全血型×全星座"专业人设，短期冲高赞藏。

## 五、避坑红线（所有建设动作遵守）

- 不当算命恐吓号：不做命运式预言、不轰炸式运势恐吓，情绪收在"更懂自己"。
- 不瞎编科学：输血/基因概率/激素代谢等用主流口径，存疑用"一般/多数/据说"。
- 不绝对贴标签：每篇收尾给"不被定义"的出口，别把读者和对象框死。
- 体质健康温和化：血型与健康关联用"倾向/容易"，不涉医疗诊断。
- 人设要稳：咨询/研究口吻前后连贯，身份标签（双子座·研究者）不自相矛盾。
- 玄学资质边界：不承诺效果、不涉及医疗建议，避免平台限流与责任风险。
